Action Mode

Press Ctrl+Shift+A to open the action ring. Release the held key over a wedge, click one, or press its letter. Digits 0 to 9 switch channel and D disables Clipnik; both are keyboard only.

Prefer a plain list? Set Menu style to List under Settings > Appearance, and the actions show as a list on the card instead: press a letter to run one, Esc to close.
