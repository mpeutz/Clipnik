How do I

Paste something older

Hold Ctrl and press V. Keep Ctrl down: each further V moves forward one clip, into what you copied earlier, and C moves back toward the newest. The card near your pointer shows where you are; release Ctrl to paste that clip.

To skip, press a digit 1 to 9 instead: it jumps that many clips ahead in one step. A returns to the newest clip.

Keep a clip at the top

Step to the clip in paste mode and press Space. The card marks it FIXED, and it keeps its position as new clips arrive instead of being pushed down. Press Space again to release it.

Q moves the clip you are on to the first position. In the Channel Organizer the same setting is the Fixed box in a clip's properties.

Put a clip on the system clipboard without pasting

Step to the clip in paste mode and press S. Paste mode closes and the clip stays on the Windows clipboard, so a plain Ctrl+V pastes it anywhere, including apps Clipnik ignores.

In the Clipboard History window, select a row and press Ctrl+C for the same result.

Paste as plain text or another format

In paste mode press Z. The format ring opens at your pointer: flick out to a wedge and release Z, click a wedge, or press its letter. With Menu style set to List in Settings, the formats open as a list on the card instead; press a format's letter. Choose Trim Formatting to drop styling, or a text format such as Upper case or Pretty JSON.

The format stays until you change it. The General page of Settings sets a default and can return every paste mode to it. The Formats topic lists the letters this build assigns.

Clean tracking parameters off a link

Copy the link, start paste mode, press Z and pick Strip URL tracking. It drops utm_*, fbclid, gclid and similar parameters and leaves the rest of the address alone.

The same thing sits in the Actions menu of a URL clip in the Clipboard History and Channel Organizer windows. A rule can apply it to every link you copy: see Make a rule fire automatically.

Paste several clips in a row

Hold Ctrl, press V until you reach the first clip, then press Enter instead of releasing Ctrl. The clip is pasted and paste mode stays open, still showing that same clip.

Press V or a digit to move to the next one, then Enter again. Release Ctrl when you are done.

Find a clip by typing

In paste mode press F and start typing. Clipnik searches every channel, jumps to the first match and shows a counter on the card; tags count as part of a clip's text. Unless you have turned on the separate search window on the Advanced page, your typing never takes focus from the app you are pasting into.

Up and Down step through the matches, Enter pastes the one you are on, and Esc cancels. The General page can open every Ctrl+V ready for typing.

Move clips between channels

Open the Channel Organizer from Action Mode (O). Select clips, then Alt+X to move them or Alt+C to copy them, and pick the target channel. Dragging them onto a channel in the left list does the same; hold Ctrl as you drop to copy.

From paste mode: tap X to step the card through Cancel paste operation, Delete current, Move current Clip, Copy current Clip and Delete all. Stop on Move or Copy, release Ctrl, and pick the channel.

Tag a clip

In paste mode press T. Paste mode ends and a box opens with the clip's current tags; type words separated by spaces and confirm.

Tags appear on the paste-mode card, are matched by paste-mode search, and can be edited in the Channel Organizer's clip properties. A rule can add a tag to every clip that matches it.

Make a rule fire automatically

Open Settings, go to the Rules page and choose Add. Pick the conditions the clip must meet: one or more clip kinds, a regular expression the text has to match, the process it was copied from, or the window class. Every condition you fill in has to hold.

Then pick one action: send the clip to a channel, ignore it, apply a format to it, or add a tag. Rules run top to bottom and the first match wins, so use Up and Down to order them. The check box in front of a rule turns it off without deleting it.

Get something back from history

Open Clipboard History from Action Mode (H) and type in the search box; the Type list narrows the rows to one kind of clip.

With a row selected: Space pastes it into the window you came from, Ctrl+C puts it on the clipboard, Ctrl+H opens it in your editor, Ctrl+E exports it to a file and Delete removes it.

Work with images

Copy an image and Clipnik stores it like any other clip, with the kind Image and its pixel size recorded; both show on the paste card, and the Clipboard History, Vault and Channel Organizer lists show a thumbnail of the image with its size, as well as the full image in the preview. Images reach the Clipboard History window only while "Store images in history" is on.

H hands the image to the editor named on the Advanced page. Paste mode ends while the editor is open, and saving there writes the change back to the clip.

Send to Squoosh, Open in image editor and Copy as data URI are also on the Actions menu in Clipboard History and the Channel Organizer, and the copy notification's chip runs Send to Squoosh. Squoosh takes no file, so Clipnik puts the image on the clipboard and opens the site ready for you to paste it.

How good that image is depends on where it came from. Straight after copying, and from the Channel Organizer, you get the original pixels. Clipboard History keeps only the preview copy, a JPEG at the quality set on the History page, so an image pulled back from there is lossy and has lost its transparency. The same applies to a data URI made from a stored clip.

A rule can also route, tag or ignore a copied image; transform never applies to images.

Work with SVG

Copy SVG markup as text -- not a rendered image -- and Clipnik recognizes it as its own kind, SVG, instead of plain text.

The Actions menu in the Clipboard History and Channel Organizer windows offers all three SVG actions: Send to SVGOMG copies the markup and opens the SVGOMG optimizer in your browser; Open in vector editor saves it to a temporary file and opens the program you set on the Advanced page (Affinity Designer, for example -- there is no default); and Copy as data URI copies an inline data:image/svg+xml,... version of the markup. The copy notification's chip runs Send to SVGOMG right away.
