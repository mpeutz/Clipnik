How do I

Paste something older

Hold Ctrl and press V. Keep Ctrl down: each further V steps one clip further back, C steps forward again, and the card near your pointer shows where you are. Release Ctrl to paste the clip on the card.

To skip several at once, press a digit 1 to 9: that many clips back in one step. A returns to the newest clip.

Keep a clip at the top

Step to the clip in paste mode and press Space. The card marks it FIXED, and it keeps its position as new clips arrive instead of being pushed down. Press Space again to release it.

Q moves the clip you are on to the first position. In the Channel Organizer the same setting is the Fixed box in a clip's properties.

Put a clip on the system clipboard without pasting

Step to the clip in paste mode and press S. Paste mode closes and the clip stays on the Windows clipboard, so a plain Ctrl+V pastes it anywhere, including apps Clipjump ignores.

In the Clipboard History window, select a row and press Ctrl+C for the same result.

Paste as plain text or another format

In paste mode press Z. The format ring opens at your pointer: flick out to a wedge and release Z, click a wedge, or press its letter. Choose Trim Formatting to drop styling, or a text format such as Upper case or Pretty JSON.

The format stays until you change it. To start every paste mode from one format instead, set Default Paste-Format and "Always start Paste mode with the default formatting" on the General page of Settings. The Formats topic lists the letters this build assigns.

Clean tracking parameters off a link

Copy the link, start paste mode, press Z and pick Strip URL tracking. It drops utm_*, fbclid, gclid and similar parameters and leaves the rest of the address alone.

The same thing sits in the Actions menu of a URL clip in the Clipboard History and Channel Organizer windows. A rule can apply it to every link you copy: see Make a rule fire automatically.

Paste several clips in a row

Hold Ctrl, press V until you reach the first clip, then press Enter instead of releasing Ctrl. The clip is pasted and paste mode stays open on the next one.

Press Enter again for that clip, or V to skip ahead first. Release Ctrl when you are done.

Find a clip by typing

In paste mode press F and start typing. Clipjump searches every channel, jumps to the first match and shows a counter on the card. Your keyboard focus never leaves the app you are pasting into.

Up and Down step through the matches, Enter pastes the one you are on, and Esc cancels. Tags count as part of a clip's text when searching.

Turn on "Start Paste mode with Search enabled" on the General page to have every Ctrl+V open ready for typing.

Move clips between channels

Open the Channel Organizer from Action Mode (O). Select one or more clips and press Alt+X to move them or Alt+C to copy them, then pick the target channel. Dragging the selection onto a channel in the left list does the same, and holding Ctrl while you drop copies instead of moves.

From paste mode: step to the clip and tap X. Each tap moves the card on one step, through Cancel paste operation, Delete current, Move current Clip, Copy current Clip and Delete all. Stop on Move or Copy, release Ctrl, and pick the channel.

Tag a clip

In paste mode press T. A box opens with the clip's current tags; type words separated by spaces and confirm.

Tags appear on the paste-mode card, are matched by paste-mode search, and can be edited in the Channel Organizer's clip properties. A rule can add a tag to every clip that matches it.

Make a rule fire automatically

Open Settings, go to the Rules page and choose Add. Pick the conditions the clip must meet: one or more clip kinds, a regular expression the text has to match, the process it was copied from, or the window class. Every condition you fill in has to hold.

Then pick one action: send the clip to a channel, ignore it, apply a format to it, or add a tag. Rules run when a text clip is copied, top to bottom, and the first match wins. Use the arrows to reorder them and the check box in the list to turn one off without deleting it.

Get something back from history

Open Clipboard History from Action Mode (H) and type in the search box. The Type list narrows the rows to one kind of clip.

With a row selected: Space pastes it into the window you came from, Ctrl+C puts it on the clipboard, Ctrl+H opens it in your editor, Ctrl+E exports it to a file and Delete removes it.

How long history keeps a clip is set on the Clipboard History page of Settings.

Work with images

Copy an image and Clipjump stores it like any other clip; the paste-mode card shows a thumbnail instead of text, and paste mode pastes it back.

Images reach the Clipboard History window only while "Store images in history" is on, on the Clipboard History page. That page also sets the quality of the stored preview.

H in paste mode opens the image in the image editor named on the Advanced page, and saving there writes the change back to the clip.
