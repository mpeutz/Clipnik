Settings

Open Settings from Action Mode (E) or the tray menu. Pages are listed down the left. OK applies your changes and closes, Apply keeps the window open, and Cancel throws them away. The link in the bottom left opens the Clipjump folder, where settings.ini lives, and the Help button next to them brings you back to this page.

General

How many clips a channel holds: whether the number is capped at all, the cap itself, and how many extra clipboards are kept before the oldest are dropped.

Paste-mode behavior: whether Ctrl+V opens with search ready, whether the active clip keeps its position, the default paste format, and whether every paste mode starts from that default.

Capture: whether Clipjump watches the clipboard at all or only records through its own shortcuts, whether clips survive a restart, and whether to skip clips that an app marks private.

Clipboard History

The long-term store behind the history window: how many days a clip is kept (0 keeps everything), whether images are stored, and the JPEG quality of stored previews.

The history window itself: whether search matches partial text by default, whether the window closes after an Insta-Paste, and whether an Insta-Paste also writes the system clipboard.

Shortcuts

The paste-mode key (the modifier badge plus one letter) and the global shortcuts for Action Mode, Clipboard History, the Channel Organizer and the Plugin Manager.

Below them: the keys that copy a file's path, its folder's path or its contents, plus Hold Clip and the one-time stop. Shortcuts left empty are simply not registered. The Global shortcuts topic shows what you have set right now.

Channels

The pit-swap key, which swaps the active channel with the channel named pit and back.

Ignored windows: the Manage button opens the list of window classes Clipjump stays out of. It does not record copies made there, and paste mode passes Ctrl+V straight through.

Rules

The list of copy-time rules, in the order they are tried. Add, Edit and Remove change the list; Up and Down reorder it; the check box in front of a rule turns it on or off.

Each row shows what the rule looks for and what it does. See the Rules topic for what the conditions and the four actions mean.

Appearance

Theme (system, dark or light) and the accent color, either the Windows accent or one you pick.

Notifications: whether a copy is confirmed on screen, where notifications appear, whether a copy beeps and at what frequency, and whether the card says "Pasting...".

The paste-mode card: leave the position empty to follow the cursor, or give it a fixed screen position.

Advanced

Capture details: whether copying the same thing twice records twice, the window classes where a cut behaves like a delete, using Win-based copy and cut shortcuts, using Win instead of Ctrl for paste mode, and running paste-mode search in a separate window for input methods that need composition.

Editors: the programs used when you edit a text clip or an image clip.

System: the process priority Clipjump runs at, and whether it flushes memory after each operation.
