Formats

In paste mode press Z to open the format ring and pick how the clip is pasted. Formats that suit the clip come first; the rest are dimmed but still usable. Your choice lasts until you change it, unless "Always start Paste mode with the default formatting" is on in Settings, which returns every new paste mode to the default paste format.

With Menu style set to List (Settings > Appearance), Z opens the same formats as a list on the card: press a format's letter to use it; Z, Esc or Enter close it unchanged.
