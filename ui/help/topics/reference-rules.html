Rules

A rule watches new clips and acts on the ones that match. Rules live on the Rules page in Settings. Each rule matches on clip kind, a regular expression, the app it was copied from, or the window class, and then performs one action.

Rules are tried when a text clip is copied, in the order they appear on the page, and the first rule whose conditions all hold is the one that runs. Copied images are not matched.

Actions

A rule carries exactly one of these:

  • channel sends the clip to the channel you name. It is still recorded in the active channel first and then moved, and the copy notification says where it went.
  • ignore drops the clip: it is not stored in any channel and not written to history. A short warning names the rule so you can see why nothing was recorded.
  • transform applies one paste format to the clip as it is stored, so what you later paste is the converted text. Pick the format from the same list as the default paste format.
  • tag adds the words you give to the clip's tags, exactly as pressing T in paste mode would.

Clip kinds

A kind is what Clipjump decided the text is. A rule that lists kinds matches only those; a rule that lists none ignores the kind entirely.
