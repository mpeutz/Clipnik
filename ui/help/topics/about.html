About

Clipnik is a clipboard manager for Windows, written in AutoHotkey. It keeps what you copy in channels, and pastes it back through paste mode.

Version .

Where this comes from

This is a fork of the original Clipjump by Avi Aryan, which is still at github.com/aviaryan/Clipjump. The link opens in your browser.

Reporting a problem

Report it wherever you got this copy of Clipnik, and say which version you are on: the number above is the one that matters.

Two things help. Say exactly what you pressed and what happened instead. If the trouble is in Clipboard History, the Channel Organizer or this Help window, attach %TEMP%\Clipnik\webhost.log, which those windows write as they run.

Double-click the tray icon, or click the header of the tray card, to open the About window. It shows the same version next to the AutoHotkey version Clipnik is running on, and it is where Reset lives.
