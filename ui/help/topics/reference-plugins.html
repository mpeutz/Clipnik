Plugins

A plugin is an AutoHotkey v2 file in the plugins folder next to Clipjump. Clipjump reads every .ahk file there at startup and takes the plugin's details from the ;@Plugin- comment lines at the top of the file.

Include plugins and external plugins

An include plugin is loaded into Clipjump itself at startup, so it runs in the same process and can read and change Clipjump's own state. Its file name has no dot in it and it defines a function called plugin_ plus that name.

An external plugin is named external.something.ahk. It is not included; Clipjump runs it as a separate script when you ask for it, and it talks back over the public API. Use one when the code should not be able to disturb the running app.

A paste format plugin is named pformat.something.ahk and defines plugin_pformat_something. It is included like an include plugin, and it joins the format ring alongside the built-in formats.

The Plugin Manager

The Plugin Manager lists every plugin it found, with its name, tags and author, and a box that filters the list. Open it from Action Mode (M), or give it a shortcut on the Shortcuts page.

Run starts the selected plugin and shows whatever it returns. Properties shows the rest of its header. Edit opens the file in the text editor named on the Advanced page. Delete removes the file and its .lib folder; Clipjump offers to restart afterwards, because included plugins are only read at startup.

The header of a paste format plugin

Each line starts with ;@Plugin- and a field name. Repeat a field and the pieces are joined with a space, so a long description can be written over several lines.

  • ;@Plugin-Name is the name shown in the Plugin Manager, in the format ring's hub and in the Default Paste-Format list.
  • ;@Plugin-Short is the one word written inside the ring wedge. Without it the ring uses the first word of the name.
  • ;@Plugin-Key is the letter you would like the format to answer to. The built-in formats claim their letters first, and a plugin that asks for a letter already taken gets the first free letter of its own name instead, so the letters you actually press are the ones in the Formats topic.
  • ;@Plugin-Description is the sentence shown under the name in the ring's hub.
  • ;@Plugin-Author and ;@Plugin-Tags fill the Plugin Manager's columns; with the name, they are what its filter box searches. ;@Plugin-Version and anything else you add show up under Properties.
  • ;@Plugin-Previewable 1 lets the paste-mode card show the clip already converted, so you see the result before you paste. Leave it at 0 when converting is slow or changes nothing on screen.
